tool-return
===========

Description
-----------
The conclusion of a tool call.

Parameters
----------
| Parameter     | Value       |
| ------------- | ----------- |
| Subject       | tool        |
| Activity      | return      |
| Activity Type | tool-return |
| Pretty Name   | Tool Return |


Fields
------

The possible fields for this activity type will vary depending on whether the activity was a [success](#tool-returnsuccess) or a [fail](#tool-returnfail).


tool-return:success
-------------------

There are no fields for this activity type.


A failure activity is not currently supported for this activity-type.
