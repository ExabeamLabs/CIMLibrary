user-mfa-modify
===============

Description
-----------
The MFA configuration for a user account was updated

Parameters
----------
| Parameter     | Value             |
| ------------- | ----------------- |
| Subject       | user              |
| Activity      | mfa-modify        |
| Activity Type | user-mfa-modify   |
| Pretty Name   | User MFA Modified |


Fields
------

The possible fields for this activity type will vary depending on whether the activity was a [success](#user-mfa-modifysuccess) or a [fail](#user-mfa-modifyfail).


user-mfa-modify:success
-----------------------

There are no fields for this activity type.


user-mfa-modify:fail
--------------------

There are no fields for this activity type.
